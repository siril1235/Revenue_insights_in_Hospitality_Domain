# 📊 Revenue Insights in Hospitality Domain

## 🔹 Project Overview

This project is a Power BI dashboard designed to analyze revenue performance in the hospitality industry. It provides insights into key metrics such as RevPAR, ADR, occupancy rate, and revenue trends across different cities and properties.

---

## 🔹 Objectives

* Analyze hotel revenue performance
* Track occupancy and booking trends
* Compare business vs luxury category performance
* Identify high-performing properties
* Support data-driven decision making

---

## 🔹 Key Metrics Explained

* **Revenue**: Total income generated
* **RevPAR**: Revenue per available room
* **ADR**: Average Daily Rate
* **DSRN**: Daily Sellable Room Nights
* **Occupancy %**: Percentage of rooms occupied
* **Realisation %**: Revenue efficiency metric

---

## 🔹 Key Features

* 📊 Interactive dashboard with filters (City, Room Class, Week)
* 📈 Trend analysis of RevPAR, ADR, and Occupancy
* 🏨 Property-level performance comparison
* 📉 Revenue distribution by category (Luxury vs Business)
* 📅 Weekly performance tracking
* 📌 Platform-wise realization analysis

---

## 🔹 Tools & Technologies Used

* Power BI
* Excel (Data Source)
* DAX (Data Analysis Expressions)
* Data Cleaning & Transformation

---

## 🔹 Dashboard Insights

* Luxury category contributes higher revenue share
* Certain cities like Mumbai and Bangalore show strong performance
* Occupancy rate remains consistent across weeks
* Platform-wise realization highlights booking efficiency
* Identified top-performing and low-performing properties
